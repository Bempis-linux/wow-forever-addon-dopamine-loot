# Dopamine Loot

Loot that feels like loot: 3D item popups, treasure rain, and an item inspector.

> Status: early development (v0.1). Clients: WoW Forever (Interface `16001`).

## Commands
- `/dl`: open or close the window
- `/dl help`: list all commands in chat
- `/dl log`: open the log window (all other output goes here, selectable and copyable)

## Install
Copy (or link) the `DopamineLoot` folder into `World of Warcraft\<client folder>\Interface\AddOns\`, then restart the game.
